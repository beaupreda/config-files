# Configuration Files

This repository contains all the configuration files for the different programs that I use. I try to go for simple and minimal configurations most of the time, staying close to the defaults as much as possible. The theme is Kanagawa Dragon, although I don't theme GTK or Qt because it's not worth the effort for me! This is not meant to be a setup that can be easily installed, but feel free to take small bits here and there if you like parts of it!
